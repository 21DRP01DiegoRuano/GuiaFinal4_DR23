  • Dominio

    Un dominio web es el nombre único e identificador de un sitio web en Internet. Se utiliza para que los usuarios puedan acceder a un sitio web de manera fácil y memorizable, en lugar de usar la dirección IP del servidor.

  • Subdominio

    Un subdominio web es una extensión de un dominio principal que permite crear secciones o sitios web separados dentro del mismo dominio

  • URL

    Una URL, o Localizador Uniforme de Recursos, es la dirección única que identifica un recurso en Internet

  • DNS

    DNS, o Sistema de Nombres de Dominio, es el sistema que traduce los nombres de dominio (como "google.com") en direcciones IP numéricas

  • Hosting

    El término "hosting" se refiere al servicio de alojamiento web, que permite a las páginas web y sus archivos estar disponibles en internet

  • FTP

    FTP (Protocolo de transferencia de archivos) es un protocolo de red estándar utilizado para la transferencia de archivos de un host a otro a través de una red basada en TCP, como Internet.

  • HTTPS

    El HTTPS (protocolo de transferencia de hipertexto seguro) es un protocolo que cifra la comunicación entre un navegador web y un sitio web, proporcionando una conexión segura

  • W3C

    El W3C, o World Wide Web Consortium, es una organización internacional sin fines de lucro que desarrolla estándares y directrices para la World Wide Web

  • UTF-8

    UTF-8 es un estándar de codificación de caracteres que permite representar cualquier carácter Unicode utilizando entre 1 y 4 bytes de datos

  • html5

    HTML5 es un estándar que define la estructura y el contenido de una página web, introduciendo elementos semánticos para mejorar la accesibilidad y la comprensión del código. La estructura básica incluye etiquetas como

    ,
    ,
    ,
    ,
    y
    para delimitar diferentes secciones de la página.
